# Dynamic Panels

**Version:** 1.0.0  
**Client:** World of Warcraft: Forever (`_classic_beta_`, Interface **16001**)

Hold **Ctrl+Shift** and drag Blizzard panel headers to move them. Resize from the bottom-right handle. ElvUI frames are skipped.

`/dp` — options

## Install

1. Download this repo or the [Release](../../releases) zip.
2. Copy the `DynamicPanels` folder into  
   `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. Restart Forever (`WowB.exe`) or `/reload`, and enable the addon.

If you use “Download ZIP” from GitHub, keep the inner folder named **`DynamicPanels`**.
